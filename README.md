# UK News Balance

A mobile-friendly news dashboard that pulls headlines from five major UK outlets side by side, so you can compare coverage across the political spectrum.

## Sources

| Outlet | Lean |
|---|---|
| BBC News | Centre / public service |
| The Guardian | Centre-left |
| The Independent | Centre-left |
| Daily Mail | Right / popular press |
| Sky News | Centre / broadcast |

## Categories

Politics · UK · World · Business · Sport · Tech · Health

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy free

Works on [Vercel](https://vercel.com), [Netlify](https://netlify.com), or [Cloudflare Pages](https://pages.cloudflare.com) with zero config. Pages revalidate every 30 minutes.
